Install the beta

  1. Download and open the DMG.
  2. Drag MyMedia Photos into Applications, then open it from Applications.
  3. Add a small folder first and try search or exact-duplicate review. Keep an independent backup before organizing or cleaning up.

Before installing

  • macOS 14 or later on an Apple Silicon Mac.
  • Developer certificate: Weidong Shao. Product: MyMedia Photos by uuBright.
  • Distributed outside the Mac App Store. Apple notarization is a security check, not an endorsement or a guarantee of feature correctness.

What changed in build 80

Organize previews now work across library views. The header separates library information from Organize folders, Free up space and Back up actions. Organize setup names its scope, disables empty previews and explains excluded visual guesses. Plan review shows destination space before Copy or Move. Offline sources remain browsable with an originals-disconnected notice. See the release notes.

Is the next build here yet?

Not yet. The guided iPhone flow with direct USB import, similar-shot review, backup check and restore, the Space view, drive setup and suggested albums are in testing and are not in build 80. See what is coming. This page will name the new build when it is published.

Known issues and testing

Visual-search relevance and broader library workflows remain under validation. Ranked visual guesses are excluded from the text/filter organize scope; select them explicitly and choose Selected photos to include them. Cloud backup is experimental: keep another copy and test restore.

The packaged Apple Silicon smoke test passed native inference, Drive configuration, normal quit and unchanged-original checks. These checks do not establish whole-product release readiness. Earlier Intel packages are not this build and lack ONNX-backed features.
