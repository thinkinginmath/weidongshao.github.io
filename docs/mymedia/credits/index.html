Build 80 · October 16, 2026

Sample photos. Real app screens.

Our sample library contains 24 distinct NASA astronaut photographs of Earth, plus four deliberate exact copies. No personal library appears in these images.

How the walkthrough was made

The 40-second edited screen tour uses screenshots captured from the signed build 80 app on a Mac, in an isolated profile. It holds each real screen with a caption; it is not a continuous recording. No app responses or results were mocked.

A read-only disk image named MyMedia Sample Drive stands in for an attached photo drive; this is not a physical USB-drive test. The app indexed its 24 photos and four copies in a Mac folder. Filenames and file-modified dates were set from NASA catalog dates to demonstrate date search and filename-based organize date recovery. No original EXIF capture-date accuracy is implied.

We reviewed four exact-copy groups and previewed an organize plan. We did not apply the plan, delete any photo, import from an iPhone or test disconnected hardware in this recording. The iPhone-guide screenshot shows the actual guide, without a connected phone.

Public-domain sources

These images are credited to NASA and U.S. astronaut photographers and are U.S. government works in the public domain. NASA does not endorse MyMedia. See NASA’s media usage guidance. No NASA seal is used as product branding.
