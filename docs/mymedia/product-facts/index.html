MyMedia Photos: what the current beta does.

A folder-first photo organizer for Mac, built by uuBright. This page describes verified release details and current feature boundaries.

Latest tested buildVersion 0.1.0, build 66 · October 13, 2026
PlatformmacOS 14 or later. The current tested build is for Apple Silicon (M-series Macs). Older Intel builds have limitations; they are not build 66.
DistributionDeveloper ID signed and notarized by Apple. Developer certificate: Weidong Shao. Public Apple Silicon beta, distributed outside the Mac App Store.
Local libraryExisting folders and connected drives, indexed in place. No proprietary library import and no account required for local folder features.
SearchFilenames, capture dates, recognized text, content labels and user-assigned people. Local visual search is experimental; it does not guarantee every relevant photo will be found. Face recognition needs a local model and manual analysis.
DuplicatesByte-for-byte exact duplicate review with keeper selection and a space estimate. Similar-shot grouping is in development.
File changesOrganization previews copy/move destinations and journals operations for undo. Editing saves renditions. Cleanup moves chosen files to Trash; it does not permanently delete them or empty Trash.
iPhone workflowImport through Apple Image Capture into a Mac folder, then create and verify another copy. MyMedia does not import directly from the phone or delete phone assets.
Optional sourcesApple Photos and Google Drive are separate browsers, not automatic folder-library indexing. Drive access is read-only and account-wide; chosen originals can be copied to the Mac.
Optional cloud backupExperimental. Google account sign-in, with file contents, names and metadata encrypted before upload. Separate from Google Drive. Keep the recovery phrase and another copy.
PriceThe first public local-app release is planned to be free. Cloud storage allowances and pricing have not been announced.

Build evidence and limitations

Build 66 includes the simplified duplicate-review selection bar. Its packaged Mac smoke test exercised native inference, checked Drive configuration, confirmed normal quit and verified its disposable original was unchanged. This does not prove every workflow or library size has passed acceptance testing.

Known issue: the organize destination review currently appears only in the People view. In All photos, requesting a preview can report proposed destinations without showing the plan. This is being corrected; do not treat a status message as an applied operation.

Website screenshots use clearly labeled demonstration data, not private customer libraries or measured search-quality evidence.

Privacy boundaries

Local photo analysis does not upload photos. An automatic daily update check contacts uuBright’s service unless disabled in About. Google Drive, place lookup, S3 copies, encrypted backup and portrait generation each have separate data boundaries. Optional website analytics is consent-gated and does not track the desktop app.

Common questions

Does MyMedia require importing into Apple Photos?

No. Its folder library indexes existing local folders and connected drives in place. Apple Photos is an optional, separate read-only browser.

Does exact duplicate review find similar photos?

No. Exact review compares file contents byte for byte. Resized exports, edited versions, burst shots and visually similar images may have different contents and are outside this feature. Similar-shot review remains in development.

Does backup verification prove my entire iPhone is backed up?

No. MyMedia verifies the files in the imported folder. It cannot confirm Image Capture imported every phone asset or every Live Photo resource. Keep the phone originals until you independently check your backup.

Is MyMedia an App Store app?

The current beta is distributed separately from the Mac App Store. Build 66 for Apple Silicon is Developer ID signed and notarized by Apple; notarization is not an endorsement or an App Store review.
