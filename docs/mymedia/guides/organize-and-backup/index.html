User guide · Updated November 7, 2026

One folder first.
Then a library you can trust.

Try a small copy-only batch before organizing years of photos. Keep your originals, check the result, and make a second copy on a separate drive.

Check your version first. The public download is still build 80. The seven-step “Organize everything” guide, the new “Back up a folder” wizard and receipt-based backup checking below are in the next beta preview, not that download. Version details and beta limits.

Start safely · Current beta · Next beta preview · Troubleshooting

Before you start

  1. Pick a home for your photos. Use a connected, writable external drive with enough free space. A folder on your Mac is fine for a small test, but it will not free Mac storage.
  2. Keep a separate backup. Use a second physical drive. Two folders on the same disk both disappear if that disk fails.
  3. Start with a few files. Choose a small source folder, or select a handful of photos in the library. For phone imports, keep the still image, video and sidecars of each Live Photo together.

Using the current public beta (build 80)

  1. Add your source folder. Use the sidebar’s + Add menu. MyMedia indexes files where they are; adding a folder does not move your originals.
  2. Review an organize plan. Select the photos you want to test, then choose Organize folders. Pick an empty test destination on your drive, use the selected-photo scope and review every destination.
  3. Choose Copy. Confirm that the action says Copy, not Move. Only apply after the file count and destination match your intended batch. Dated folders use capture metadata where available; inspect files marked for date review.
  4. Make a verified folder copy. Build 80’s local backup guide uses iPhone/Image Capture wording. If your files are already in a folder, skip the import instructions, choose that folder and copy it to a second drive. Review the verified counts and the receipt saved beside the copy.
  5. Open samples from the second drive. Check photos, videos and companions you care about. Keep the source originals while you resolve anything skipped, changed or conflicting.

For phone imports, use the build-80 iPhone guide. For multiple drives, see external-drive guidance.

Next beta preview: Organize everything

Once you have the next beta, open Back up → Organize everything. Its Space report stays visible while you work through these steps:

  1. Home. Choose the Photo Drive folder where originals will live. A second folder on that drive is not an independent backup.
  2. Scan. Add folders without copying them. Large folders open a survey: expand a parent folder to inspect its groups, use Show samples and click a sample for a readable preview. Exclude an entire unwanted library subtree rather than unticking every child. Scanning reaches 12 folder levels below your selected folder; deeper folders are reported and can be added separately.
  3. Free space. Review exact copies and old screenshots. The reclaimable total follows that review; large videos and similar-shot estimates are shown separately. Nothing goes to Trash just by opening the report.
  4. Add sources. Choose an explicit import or gather action and confirm the destination in its picker. Keep phone and cloud originals. Camera-mode Huawei/Android import is limited to what the device exposes; it is not full MTP or app-folder support.
  5. Review copies. Pick a keeper for exact duplicates. Review similar shots visually; a suggested keeper is a starting point, not permission to delete.
  6. Organize. Preview dated folders. Start in Copy mode, confirm the selected scope and destination, then apply. Open History for the recorded result.
  7. Back up. Choose Make a verified drive copy, or use Back up → Back up a folder directly. Choose the source folder, review its size, then choose the second drive. New source folders also join the library; large folders need their survey reviewed first.

Check the proof

Organize History lists files kept, copied and hash-verified, with CSV export. “Nothing lost” appears only for a finished, trusted step with an outcome for every file and none needing attention. It is not a promise that every source or phone asset has been found.

A folder backup has its own .mymedia-backup.json receipt beside the copy. Use Back up → Check or restore a backup, select the backup folder and choose Check backup now. This rereads files against the receipt without needing the source. For an extra test, restore into a new folder and open representative samples.

If something needs attention

  • Drive disconnected or swapped: reconnect the intended drive and check its identity. Do not use a different disk with the same name as proof that the original returned.
  • Not enough space: choose another drive or a smaller batch. Organize and verified folder-copy operations preserve the Mac’s reserve of at least 5 GB or 5% of disk capacity, whichever is larger.
  • Interrupted backup: reconnect the same source and destination and run it again. Matching files are verified; name conflicts are reported rather than overwritten.
  • Skipped links or online-only files: read the receipt. Links are not followed and placeholders are not silently downloaded. A partial copy is not a complete backup.
  • Wrong date: inspect the proposed folder before applying. Missing capture dates need review; a file’s modification date is not always the date the photo was taken.
  • Ready to clean up: first check the receipt, a separate backup and sample restores. Review every proposed removal. MyMedia never empties Trash; space returns only when you empty it yourself in Finder.
