Practical guide · Exact copies across folders

Choose a keeper. Clear the extra copies.

An old drive, a download folder and an export can hold the same photo. MyMedia groups files with identical contents so you can compare their locations before removing anything.

Coming in the next beta build (not in build 80): a separate Similar shots review for repeated takes of the same moment. It suggests one to keep and says why, shows the takes side by side in Compare, and leaves the choice to you. Nothing is removed automatically. Exact-copy review below is unchanged.

1. Add and connect the folders

Add ordinary Mac folders or mounted drive folders from Folders → Add. Let the date-and-duplicate indexing pass complete. Exact comparison uses the file contents, not how similar two thumbnails look.

2. Open Exact duplicates

Use the sidebar or the Overview recommendation. Each group lists where its copies live. A disconnected source’s saved hash is not accepted as a connected keeper; reconnect drives if a group seems to be missing.

3. Choose the copy you want to keep

Compare the full location, filename and your storage preference. Choose the keeper, then select only extra copies. A copy in another folder can be intentional; identical content alone is not a reason to remove it.

4. Review the space estimate and removal

The estimate covers selected extra files, not disk space already freed. MyMedia rechecks connected originals before cleanup. Move to Trash uses macOS Trash; it does not empty Trash or permanently delete files. Keep an independent backup and verify the keeper remains usable.

What will not match?

A resized export, recompressed image, edited rendition or Live Photo MOV companion has different bytes and may not join the same group. Similar shots are not part of exact-duplicate cleanup; see the note above about similar-shot review. Metadata differences can change file contents even when thumbnails look alike.

Troubleshooting

  • No groups: check that all intended folders are connected and indexing has finished. Clear search/folder filters before comparing.
  • A copy disappeared: the source may be disconnected or the file may have changed since the last scan. Rescan before deciding.
  • Removal is paused: review any library-integrity warning. Never treat a cached preview as a full original or backup.
  • Space did not immediately return: Trash contents still occupy storage. Review them independently; MyMedia never empties Trash.
